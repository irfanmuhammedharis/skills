# skills

397 agent skills for Claude Code, Codex, Cursor, OpenCode and other agents that read `SKILL.md`.
15 are my own; the rest are third-party skills redistributed under their own licences (see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)).

## Install

All of them:

```
npx skills add irfanmuhammedharis/skills -g
```

Loading hundreds of skills at once costs context in every session, so picking a few is usually better:

```
npx skills add irfanmuhammedharis/skills -g --list
npx skills add irfanmuhammedharis/skills -g --skill kicad-mcp-expert
```
